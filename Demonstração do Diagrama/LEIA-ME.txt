COREMOTIOM — CASOS DE USO (PÁGINA DE APRESENTAÇÃO)

O que é
Esta página mostra, em linguagem simples, tudo o que dá para fazer no
CoreMotiom: 48 situações do dia a dia, separadas em seis áreas. Ela é feita
para qualquer pessoa entender, mesmo sem conhecer o projeto.

Abrir no computador
1. Extraia todos os arquivos do ZIP para uma pasta.
2. Abra o arquivo index.html no navegador.
3. Mantenha os arquivos todos juntos (a página precisa do diagrama.svg).

A página não usa internet, contas, banco de dados ou instalação. As letras
também não dependem de fontes externas.

Publicar para enviar um link (sem GitHub)
1. Entre em https://app.netlify.com/drop
2. Extraia o ZIP e arraste a pasta que contém o index.html para o site.
3. O Netlify mostra um endereço. Copie e envie para quem quiser.
4. Para atualizar, envie a pasta de novo na mesma área de publicação.

Consulte as condições do plano de hospedagem escolhido.
Instruções oficiais do Netlify:
https://docs.netlify.com/deploy/create-deploys/#drag-and-drop

Enviar por e-mail ou WhatsApp (sem publicar)
Envie o ZIP. A pessoa extrai a pasta inteira e abre o index.html em um
computador. Funciona mesmo sem internet. No celular, o melhor é publicar e
enviar o link.

Como andar pelo desenho
- Arraste o desenho para mover.
- Use a roda do mouse para aproximar; no celular, use dois dedos.
- "Ver tudo" mostra o conjunto; os botões coloridos mostram uma área.
- "Como ler" (no celular) explica o desenho em palavras simples.
- O quadro "Onde estou" (canto) mostra a parte visível e permite clicar.
- Teclas: setas movem, + e − aproximam, 0 mostra tudo, 1 volta ao tamanho real.

Cuidado com a leitura dos dados
Os 48 casos e as relações vêm do documento mestre do projeto. O ponto
amarelo marca um assunto que ainda precisa ser definido; a ausência do ponto
não significa que a função já funciona em produção. Em especial, frete e
pagamento no código analisado usam simulações, não integrações reais.

Privacidade
A página não tem senha: ao publicá-la, qualquer pessoa com o link verá o
diagrama. O pacote não inclui o código do produto, arquivos .env nem
credenciais. O preview dentro do Arena serve para conferir o trabalho; para
acesso fora da sessão, publique em um serviço de páginas estáticas.
